Lecture 4: Binary Search Trees (BST) Notes

A binary search tree is a rooted binary tree data structure with the key of each internal node being greater than all the keys in the respective node's left subtree and less than those in its right subtree.

Key Operations:
1. Search: O(log n) average, O(n) worst case.
2. Insertion: O(log n) average, O(n) worst case.
3. Deletion: O(log n) average, O(n) worst case.

Example Tree:
       8
      / \
     3   10
    / \    \
   1   6    14
      / \   /
     4   7 13
